# Fims AI

**Your AI. Your Device. Your Privacy.**

Fims AI is a desktop AI assistant designed to bring local AI conversations to your Windows computer. The project aims to make AI accessible through a desktop interface, with support for local language models.

## ✨ Features

- 🧠 **Local AI:** Designed to work with GGUF language models.
- 🔒 **Privacy-focused:** Run supported models locally without requiring a cloud AI API.
- 💬 **Chat Interface:** Interact with your AI through a desktop application.
- 📁 **Knowledge Files:** Project includes a knowledge folder for supported local resources.
- ⚙️ **Configurable:** Uses a configuration file to manage app settings.
- 🖥️ **Windows Desktop App:** Launch the packaged application without opening VS Code.

*Features depend on your installed model and application configuration.*


## 🚀 Installation

1. Download `FimsAI-Windows.zip` from Releases.
2. Extract the ZIP file.
3. Keep all required application files together.
4. Follow the model setup instructions included with the release.
5. Launch `FimsAI.exe`.

## 🧠 Model Setup

Fims AI is designed to use compatible GGUF models.

- Download a compatible model separately if it is not bundled with the release.
- Place it in the required `models` folder.
- Follow the model configuration instructions provided with the application.

**Note:** Model compatibility, memory requirements, and performance depend on the selected model and your hardware.

## 💻 System Requirements

- Operating System: Windows 10 or Windows 11, 64-bit
- Storage: Enough space for the application and selected model
- RAM: Depends on the model size and quantization
- Internet: May be needed to download the application or model; local inference can work offline when all required files are available

## 🔐 Privacy

Fims AI is intended for local AI use. Actual privacy and network behavior depend on the application's implementation and its dependencies.

## 🛠️ Technology

- Python
- PyQt6
- GGUF-compatible local AI models
